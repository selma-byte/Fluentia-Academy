# Fluentia Academy
 
A web application for managing a languages academy: scheduling, student registration, payments, grades, attendance and communication with parents.
 
Bachelor's thesis project, Department of Computer Science, University of Jijel (2025–2026).
 
## About the project
 
Fluentia Academy gives each type of user their own dashboard:
 
- **Administrator**: manages staff, payroll, teacher applications and the school profile.
- **Secretary**: registers students, records payments, builds schedules and generates documents.
- **Teacher**: marks attendance and enters grades.
- **Student**: follows the schedule, grades and payments, and downloads receipts.
- **Parent**: follows the progress of one or more children.
Built with React (Vite), Tailwind CSS and Supabase.
 
## How to run
 
You need [Node.js](https://nodejs.org) and [Git](https://git-scm.com) installed.
 
```bash
git clone https://github.com/selma-byte/Fluentia-Academy.git
cd Fluentia-Academy
npm install
npm run dev
```
 
Then open `http://localhost:5173` in your browser.
 
> The app needs a `.env` file with the project's backend credentials. It is not included in the repository.
